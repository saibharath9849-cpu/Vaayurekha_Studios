# Vaayurekha Studios

A luxury handmade art studio website built for Vaayurekha Studios.

## Project files

- `index.html` — homepage with luxury brand styling, categories, gallery, order process, about section, testimonials, and footer.
- `styles.css` — premium styling with warm ivory beige, soft nude sections, deep brown text, and gold accents.

## How to view

1. Open `Vaayurekha_Studios_2/index.html` in your browser.
2. No build tools are required.

## Notes

- Uses Google Fonts: Allura, Cinzel, Cormorant Garamond, Poppins.
- Uses Font Awesome for icons.
- Images are loaded from Unsplash for a premium visual moodboard.
